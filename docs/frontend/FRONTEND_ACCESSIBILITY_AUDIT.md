# PROJECTHIVE: FRONTEND ACCESSIBILITY AUDIT (WCAG 2.2 AA)

- Semantic HTML tags (`<nav>`, `<main>`, `<header>`, `<section>`, `<article>`).
- Visible focus rings on all interactive inputs and buttons (`focus-visible:ring-2`).
- Accessible contrast ratios meeting 4.5:1 on text and 3:1 on graphical controls.
- Screen-reader friendly aria-labels on icon buttons.
