## 🏛️ About BITA

**BITA** is a technology organization dedicated to engineering high-velocity, human-centered platforms that bridge academic collaboration, software tooling, and artificial intelligence. We architect resilient systems characterized by zero-trust security, sub-100ms latency ergonomics, and meticulously unified design systems.

## 🐝 Flagship Products

### 🚀 [ProjectHive](https://github.com/bita-studio/Project-Hive)
*The Next-Generation University Collaboration Mesh, Teammate Discovery & Real-Time Project Incubation Ecosystem.*

- **Live Platform**: [projecthive-bd.vercel.app](https://projecthive-bd.vercel.app)
- **Core Capabilities**:
  - 👥 **Smart Squad Matchmaking**: Multidimensional skill-matching across 50+ university campuses.
  - 🎙️ **LiveKit 4K SFU Calling**: Managed WebRTC low-latency audio/video conference rooms with screen share.
  - ⚡ **Real-Time Messenger**: Socket.IO direct and squad messaging with procedural audio chimes.
  - 🧠 **HiveMind Multimodal AI**: Multi-tier cascading AI studio (Groq LLaMA 3.3 70B & Google Gemini 1.5 Flash).
  - 🛡️ **Zero-Trust Admin Console**: Complete operational oversight with real-time PostgreSQL telemetry.
- **Tech Stack**: Next.js 16 (App Router) · React 19 · TypeScript · Supabase PostgreSQL · LiveKit SFU · Express 4.x.

## 🛠️ Engineering Principles

1. **Obsidian Precision**: Every interface is designed with uncompromising visual hierarchy, tactile micro-interactions (`tap-press`), and adaptive dark/light tokens.

3. **Real-Time Performance**: Native WebSocket clusters and selective pub-sub architecture minimizing event loop lag.
