## 🚀 Local Development

```bash
# Install dependencies
npm install

# Run the dev server on port 3000
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Admin Portal: [http://localhost:3000/admin/login](http://localhost:3000/admin/login)
